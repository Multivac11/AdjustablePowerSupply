## 第12页

MP4201功能原理

Line drop compensation and OCP hiccup are disabled automatically.

When set DIR bit = 0 and DIR pin = low, no matter the Battery Charging EN control bit value, the MP4201 works in buck-boost operation only. The current flow is from VOUT to VIN. This mode can be used for battery discharge function. If it is in battery discharge mode, the input UVLO, input OVP should be set at proper value that is determined by customer application, and suggest to disable input regulation function by I2C control as well.

When set Battery Charge EN = 0, DIR bit = 1 or DIR pin = high, the MP4201 works in buck-boost mode only. The current flow is from VIN to OUT, internal battery charging function doesn't work, the output OVP is 120% of Vout, OCP mode is controlled by register setup.

If the power direction need be changed, the EN pin should be pulled low or set I2C EN = 0 (0x01 = 0). Then DIR logic can be changed; when the EN pin = 1 or I2C EN = 1, the buck-boost direction status is latched and cannot be changed again.

When output discharge function is disabled there is no 300ms output shutdown discharge time, so the system can be reset after inductor current drops to zero, it is OK to change the direction again; when output discharge function is enabled, it needs extra 300ms discharge time to reset the system, so suggest to add 500ms delay time to change the direction again.

Note: 10) When set in battery discharge function (Buck-boost mode, OUT to VIN), suggest to set proper input UVLO threshold, disable input OVP and input regulation function.

# PMBUS INTERFACE

# PMBus Serial Interface Description

The power management bus (PMBus) is an open-standard power management protocol that defines a means of communication with power conversion and other devices.

The PMBus is a two-wire, bidirectional serial interface, consisting of a data line (SDA) and a clock line (SCL). The lines are pulled to a bus voltage externally when they are idle. When connecting to the lines, a master device generates an SCL signal and device address and arranges the communication sequence. This is based on I²C operation principles.

# Start and Stop Conditions

The start and stop conditions are signaled by the master device, which signifies the beginning and end of the PMBus transfer. The start condition is defined as the SDA signal transitioning from high to low while the SCL is high. The stop condition is defined as the SDA signal transitioning from low to high while the SCL is high (see Figure 13).

The master then generates the SCL clocks and transmits the device address and the read/write direction bit (R/W) on the SDA line. Data is transferred in 8-bit bytes by the SDA line. Each byte of data is followed by an acknowledge bit (ACK).

# PMBus Update Sequence

The MP4201 requires a start condition, a valid PMBus address, a register address byte, and a data byte for a single data update. The device acknowledges receipt of each byte by pulling the SDA line low during the high period of a single clock pulse. A valid PMBus address selects the MP4201. The device performs an update on the falling edge of the LSB byte.

# PMBus Bus Message Format

In the tables in Figure 14, unshaded cells indicate that the bus host is driving the bus actively, and shaded cells indicate that the MP4201 is driving the bus.

S = Start condition
Sr = Repeated start condition
P = Stop condition
R = Read bit
W = Write bit
A = Acknowledge bit (0)
Ā = Acknowledge bit (1)

"A" represents the acknowledge bit. The ACK bit is typically active low (logic 0) if the transmitted byte is received successfully by a device.

# MP4201寄存器配置

# PMBUS COMMAND INTRODUCTION

# OPERATION (01h)

Format: Unsigned binary

The OPERATION command is used to configure the operational state of the converter. Bold font is the default.

Default Operation value is set both by I2C/OTP and ADDR pin. Either OTP = 80h or ADDR sets EN on, the chip will auto turn-on output. After power up, operation bit can be changed by i2c.

# CLEAR_FAULTS (03h)

The CLEAR_FAULTS command is used to clear any fault bits that have been set. This command clears all bits in all status registers simultaneously. At the same time, the device negates (clears, releases) its ALT# signal output if the device is asserting the ALT# signal.

The CLEAR_FAULTS command does not cause a unit that has latched off for a fault condition to restart.

If the fault is still present when the bit is cleared, the fault bit shall immediately be set again and the host notified by the usual means. This command is write only. Refer to Send Byte format.

# VOUT_COMMAND (21h)

Format: Unsigned binary

The VOUT_COMMAND register value is to set the output voltage in both charging mode and discharging mode.

When power flow is from VIN to OUT, the VOUT COMMAND sets the internal FB reference and regulation voltage of OUT pin.

When power flow is from OUT to VIN, the VOUT_COMMAND sets the internal FB reference and regulation voltage of VIN pin.
